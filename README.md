# GCP Energy Lakehouse

An end-to-end energy data engineering pipeline built on Google Cloud Platform using EIA energy data.

## Architecture

EIA API
    ↓
Python Ingestion
    ↓
Cloud Storage
    ↓
Dataproc + Apache Spark
    ↓
BigQuery
    ↓
Pub/Sub

## Technologies

- Python
- Google Cloud Storage
- Dataproc
- Apache Spark
- BigQuery
- Pub/Sub
- SQL
- EIA API

## Project Structure

See the repository directories for ingestion, processing, streaming, configuration, tests, and documentation.
